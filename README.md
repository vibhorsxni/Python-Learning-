# Basic Learning Projects 🐍

This branch contains a collection of basic Python projects built as part of my learning journey.

## Projects

- 🪨 **Rock Paper Scissors** – A classic hand game built in Python
- 🏠 **Rent Calculator** – A simple rent splitting/calculation tool
- ☕ **Chai Menu** – A menu-based ordering system
- ⏳ **Remaining Time Calculator** – Calculates remaining time in a Day
- 💰 **Simple Interest Calculator** – Computes simple interest based on principal, rate & time
- 🪙 **Coin Toss Game** – A random coin toss game with heads or tails
- 🏆 **Playing Position Decider** – Randomly assigns playing order for a group of players
- 🏴‍☠️ **Find the Treasure** – A matrix-based treasure hunting game with dynamic grid & chances
